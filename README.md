### 👋 Hey, I'm Deemanth

I am an **AI Systems Engineer** focused on building production-grade autonomous agent meshes, distributed model serving infrastructure, and resilient full-stack commercial software. My work bridges low-level AI systems engineering—such as GPU KV-cache optimizations and runtime code execution sandboxes—with real-world commercial software actively running in production and serving daily users.

#### 💡 Core Engineering Tenets:
- 🔌 **Decoupled Tool Protocols (MCP) & Type-Safe Orchestration**: In **AetherMesh**, autonomous agents communicate over Anthropic’s **Model Context Protocol (MCP)**, with deterministic typed generation enforced by **PydanticAI** and durable time-travel state machines via **LangGraph**.
- ⚡ **High-Throughput Serving & Prefix Caching**: In **RadixGate**, inference for **DeepSeek-R1** reasoning models is accelerated via the **SGLang Runtime (SRT)** using RadixAttention for automatic tree-based KV-cache sharing and zero-overhead thought-token (`<think>`) streaming.
- 🛡️ **Code-as-Action over Coordinate Automation**: In **Agent X**, rather than relying on brittle pixel bounding boxes, the system synthesizes typed Python programs at runtime to inspect OS accessibility trees and execute inside a sandboxed environment protected by 5-layer AST guardrails.
- 🎙️ **Resilient Dual-Mode Pipelines**: In **E-santhe**, high-throughput cloud streaming via **Gemini 2.5 Live Speech-to-Speech** (with acoustic barge-in) pairs with a 100% offline local fallback pipeline (**Faster-Whisper + Ollama + Piper TTS**) to guarantee zero telephony downtime.
- 📄 **Multi-Model Consensus & Exact Mathematical Verification**: In **Paper-to-Structured-Data**, messy handwritten ledgers (*khatas*) are arbitrated across multiple vision models with confidence voting and deterministic row math audits (`qty × price = total`).
- 🏛️ **Isolated Execution & Verified Citations**: In **Chaturya**, local on-premise embeddings (**LM Studio + Qdrant**) enforce exact excerpt checking, while generated Python code executes within an isolated **Docker sandbox** with automated test-case assertion loops.
- 🚀 **AI Co-Engineered Velocity & Production Craftsmanship**: Commercial systems co-engineered with frontier AI harnesses—leveraging modern agentic workflows to multiply engineering velocity while maintaining strict ownership of core system architecture, database design, security sandboxes, and native platform integrations.
